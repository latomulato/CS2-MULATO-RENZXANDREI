# Fare Calculator 

## Description
This program calculates fares.

## Version 1
- Input: Accepts name, accepts distance, and accepts passengers 
- Process: Calculates and displays the fare. 
- Output: Displays fare. 
- Does not include input validation.

## Version 2
- Input: Accepts name (with no blanks), accepts distance (not zero), and accepts passengers (only positive whole numbers)
- Process: Calculates and displays the fare. 
- Output: Displays fare. 
- Includes input validation.
